# PowerShell & Zshell Learning Project

A project to learn and explore PowerShell and Zshell scripting.

## Project Structure

- `/scripts/` - PowerShell and shell scripts
- `/notes/` - Learning notes and documentation
- `/examples/` - Code examples and exercises

## Getting Started

This project contains scripts and examples for learning PowerShell and Zshell.

## Requirements

- PowerShell 5.0+
- Zshell (zsh)
